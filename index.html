Celestial Escape

Tu es à bord du Thousand Sunny, attaqué par la Marine. Explore le navire, parle à l’équipage et trouve un moyen de t’enfuir en moins de 15 minutes.

Code source
Chargement de la machine Java…Le premier lancement télécharge environ 10 Mo, puis le jeu démarre et te demande ton prénom.

Comment jouer

  • Entre ton prénom, puis clique sur Start ou tape start.
  • Déplace-toi avec les boutons de direction ou des commandes comme go nord.
  • Tape help pour la liste des commandes.
  • Le chrono démarre avec la partie : 15 minutes pour t’échapper.

Le projet

Jeu d’aventure de type Zuul écrit en Java avec BlueJ (programmation orientée objet, ESIEE Paris, 2024). Le jeu d’origine est une application Swing ; il tourne ici dans une machine Java complète compilée en WebAssembly.

Java dans le navigateur grâce à CheerpJ (Leaning Technologies). Projet de fan, sans lien avec Eiichiro Oda, Shueisha ou Toei Animation.
